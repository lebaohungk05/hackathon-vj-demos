# Ảnh chụp màn hình

Ảnh dùng trong tài liệu (README, `docs/manual`, `docs/design`). Đặt tên theo thứ tự và nội dung, ví dụ `01-intro.png`, `02-rain-44mm.png`.

Có thể tạo lại ảnh bằng `python scripts/capture.py --no-video`; kết quả nằm trong `outputs/shots/` (không commit), chọn ảnh cần dùng rồi chép vào đây.

Dùng đường dẫn tương đối khi chèn ảnh, ví dụ `![Intro](../assets/screenshots/01-intro.png)`. Giữ mỗi ảnh dưới khoảng 500 KB.
